## Conventions

- Positions are 0-indexed; ranges are half-open `[left, right)`.
- Structures own their storage (`std::vector`), no external buffers.
- Anything monoid-based is parameterized by a value type and a combining operation, with an explicit identity — never an implicit default-constructed identity.
